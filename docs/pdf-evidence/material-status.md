## Крупные файлы и ограничения

Папка [выкроек и материалов Dead Space](https://yadi.sk/d/99gb81cUzQZcgg) показывает PSD размером 766,5 МБ, TIF 62,3 МБ и SVG 34,8 МБ. Сервис предупреждает о сбоях скачивания. Эти файлы не скачаны и не проверены; хранение их полного комплекта в обычном Git PR непрактично. Дополнительно нужно проверить авторство каждого файла и выбрать отдельное хранилище.

Бывший адрес конкурса BudgetApps сейчас ведёт на сервис кредитов; его нельзя принимать за исторический сайт. Устаревшие адреса, показавшие капчу, 404 или оболочку входа, не выдаются за сохранённые публикации.
