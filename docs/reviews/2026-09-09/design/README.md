# Новый дизайн главной

Главная RU/EN переведена на общий компонент `src/components/HomePage.astro`. Остальные страницы сохраняют предыдущий дизайн и сделанные исправления.

- Кремовый фон, графитовый текст и жёлтый акцент; спокойная системная типографика с кириллицей, обычный регистр заголовков.
- На компьютере текст и крупный портрет стоят рядом. На телефоне портрет расположен рядом с именем, а текст и кнопки занимают всю ширину.
- Избранные работы показывают реальные изображения OwlEye, Dead Space и подкаста. Изображения взяты из существующих материалов сайта, оптимизированы через Astro Picture, загружаются в AVIF/WebP.
- Вместо пёстрых рамок у каждого раздела — компактный список с тонкими разделителями.
- Контакт выделен отдельным жёлтым блоком; сохранены ссылки на социальные профили.
- Тёмная тема, клавиатурный фокус и reduced-motion учтены. Title/description главных страниц сохранены.
