*Самостоятельный архивный конспект по [оригинальному источнику](https://blogs.microsoft.com/accessibility/nokia-announces-winners-of-its-contest-for-windows-phone-apps-for-vision-impaired-users-2/); не является полной копией.*

David Dzumba, Senior Program Manager по доступности Microsoft, сообщает результаты конкурса Nokia Create Do Good Mission для приложений Windows Phone, помогающих людям с нарушениями зрения. Дата публикации на доступной странице не указана.

Победителем назван TheFunnies, а EyeLens перечислен среди других призёров (runners-up). Microsoft описывает определение цвета и увеличение изображения, а также управление жестами для смены фильтра и масштаба. В этой публикации имя Антона не названо: она подтверждает результат проекта, но не устанавливает авторство.
